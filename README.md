# Two-Level Security System

A desktop security system using barcode authentication, face recognition, OTP email verification, and encrypted file access.

## Features
- Barcode + Face Authentication
- Email OTP Verification
- Folder Encryption/Decryption
- Intrusion Alert Emails
- Mesa Simulation Integration

## Tech Stack
- Python
- CustomTkinter
- OpenCV
- Face Recognition
- Cryptography
- SQLite
- Mesa

## How to Run
```bash
python main.py
